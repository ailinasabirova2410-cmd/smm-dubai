## 2. ⚠️ Лимит Netlify — главное операционное правило

Бесплатный тариф = **300 кредитов/мес**, 1 публикация = 15 кредитов → **~20 публикаций в месяц**. Расчётный период обнуляется **13-го числа**. В сентябре лимит сожгли за неделю мелкими деплоями; с 19.09 по 13.10 публикации стояли на паузе.

Правила:
- **Правки копить пакетами** и выкатывать одним деплоем
- Коммиты, не меняющие сайт (документация и т.п.), помечать `[skip netlify]` в сообщении коммита — сборка пропустится без расхода кредитов
- Если деплои снова «Skipped» — смотреть Usage & billing: app.netlify.com/teams/ailinasabirova2410/billing
- Айлина решила: не платить и не переезжать, живём в лимите

## 3. Как устроен сайт

Чистая статика, без сборки: `index.html` + `css/style.css` + `js/app.js`. Шрифты Google Fonts: Cormorant Garamond (заголовки/цифры), Manrope (текст), DM Mono (лейблы капсом).

**Дизайн «Ink & Ivory»** — тёмный editorial. Палитра строго из четырёх цветов её Instagram (@smm.ai.uae):
- `#1A1A1A` чёрный — фон
- `#1F2B48` нави — карточки, полосы
- `#F1ECE3` крем — текст
- `#D6A8B4` розовый — акценты и цифры
Никакого золота/шампани — Айлина явно просила только её палитру.

**Двуязычность:** EN зашит в разметке (атрибуты `data-i18n`), RU подставляется из словаря. Источник текстов — `content/site.json` (структура `texts.<секция>.<ключ>.{ru,en}` + `nums` + `prices` + `images`); app.js грузит его в рантайме, встроенный словарь RU в app.js — только фолбэк. **Любую правку текста делать в трёх местах: index.html (EN), app.js (RU-словарь), content/site.json (оба)** — иначе разъедется с админкой.

**Админка** редактирует `content/site.json` через GitHub API (коммитит в main → автодеплой). Поля описаны в `admin/config.yml` — при добавлении новых ключей обновлять и его.

**Логотип:** реальный знак Айлины (рукописная «a» с росчерком) — `img/logo.png` (круг), `img/logo-a.png`/`logo-a-rose.png` (глиф), фавиконки, водяной знак за фото героя. Исходник: `tools/logo_source.jpg`.

**Анимации:** стаггер первого экрана, счётчики цифр (data-count), бегущая строка ниш, появление секций (.rise), веер Reels с наклонами. Всё уважает prefers-reduced-motion.
